# Code repris d'autres projets

`src/validators.js` porte des fonctions de validator.js 13.15 (isEmail, isFQDN, isIP, isLength, isInt, isFloat,
normalizeEmail…), et `src/validation.js` reprend le fonctionnement des chaînes d'express-validator 7.3 (éléments de
chaîne, sélection des champs, résultats). Les deux projets sont publiés sous licence MIT ; leurs mentions suivent.
